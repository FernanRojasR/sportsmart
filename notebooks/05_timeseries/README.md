# 05_timeseries

Pronóstico de ventas a 7, 30, 60 y 90 días (descomposición, SARIMA, SARIMAX y Prophet). Validación con los últimos 6 meses y con la temporada alta de 2025.

- `05_pronostico_ventas.ipynb`: compara los modelos y genera el pronóstico. Salidas: `reports/series.json` y `reports/pronostico_ventas.csv`.

Nombre sugerido: `05_<tema>.ipynb`
