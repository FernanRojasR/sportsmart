# 07_regression

Regresión de ventas por producto y mes, con el valor futuro del cliente como análisis secundario. Métricas: RMSE, MAE, R².

- `07_regresion_ventas.ipynb`: compara modelos y mide los factores que explican las ventas. Salidas: `reports/regresion.json` y `reports/predicciones_regresion.csv`.

Nombre sugerido: `07_<tema>.ipynb`
